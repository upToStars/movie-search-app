# Movie Search App

A vanilla JavaScript movie search project built as a learning exercise.

## Features
- Search OMDb movies by title
- Paginated results with `IntersectionObserver` infinite scrolling
- Movie details, favorites, and localStorage persistence for favorites
- Loading and basic error states

## Try it
Open `index.html` (or visit the GitHub Pages URL). Obtain a free OMDb API key from https://www.omdbapi.com/apikey.aspx and enter it in the app before searching. The key is **not** committed to the repository. The key is supplied to OMDb directly from your browser; browser-based API keys are not secret from browser/devtools/network requests.

## Technologies
HTML, CSS, JavaScript, OMDb API, localStorage, IntersectionObserver.

## Notes
This is an educational project and can be improved with more comprehensive errors, accessibility, visual refinements, and end-to-end testing.
